# 🍕 Pizza Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes pizza sales data using **PostgreSQL** and visualizes business insights through an **interactive Power BI dashboard**. The goal is to understand sales performance, customer ordering patterns, and the best and worst performing pizzas.

## 🛠️ Tools & Technologies
- PostgreSQL
- Power BI
- Power Query
- DAX
- CSV Dataset

## 📊 Key Performance Indicators (KPIs)
- Total Revenue
- Total Orders
- Average Order Value
- Total Pizzas Sold
- Average Pizzas per Order

## 📈 Analysis Performed
- Monthly Revenue Trend
- Daily Order Trend
- Sales % by Pizza Category
- Sales % by Pizza Size
- Quantity Sold by Category and Size
- Revenue by Pizza Name
- Top & Bottom Performing Pizzas
